# 🎵 Spotify Listening Analysis Dashboard – Excel

## 📌 Project Overview

This is a Data Analytics project focused on analysing Spotify listening history and identifying listening patterns through an interactive Excel dashboard.

The dataset was collected from **Maven Analytics** and cleaned and transformed using Power Query in Microsoft Excel.

## 📊 Project Objectives

- Analyse overall Spotify listening activity.
- Identify the most-played songs and artists.
- Understand listening behaviour throughout the day.
- Compare shuffle and non-shuffle listening patterns.
- Explore skip rates and listening trends.

## 📂 Dataset Source

- Source: Maven Analytics
- Dataset: Spotify Listening History
- The dataset was used for educational and personal project purposes.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Data Visualization

## 🧹 Data Cleaning & Transformation

Power Query was used to clean and prepare the dataset before analysis.

The process included:
- Data preparation and transformation.
- Cleaning and organizing the dataset.
- Preparing fields for analysis.
- Ensuring data was suitable for dashboard development.

## 📈 Key Analysis

The dashboard explores:

1. Total music plays and overall skip rate.
2. Top 10 most-played songs and their skip rates.
3. Listening activity by hour of the day.
4. Shuffle vs. non-shuffle listening behaviour.
5. Top artists and listening trends across 2023 and 2024.
